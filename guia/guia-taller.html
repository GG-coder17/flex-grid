Parte 1 — CSS Flexbox

¿Qué es Flexbox?

Flexbox (Flexible Box Layout) es un modelo de diseño unidimensional: distribuye elementos a lo largo de un eje (horizontal o vertical) a la vez. Es ideal para componentes de interfaz: navbars, tarjetas, formularios, barras de herramientas.

Eje principal vs. eje transversal

El eje principal (main axis) corre en la dirección de flex-direction (por defecto row = horizontal). El eje transversal (cross axis) es perpendicular a él. justify-content controla el eje principal; align-items controla el transversal.

PropiedadValores claveEfecto

💡 Truco — shorthand flex

flex: 1 equivale a flex: 1 1 0: el ítem crece, encoge y su base es 0 (ocupa espacio proporcional). flex: none equivale a flex: 0 0 auto: tamaño fijo, no crece ni encoge.

Parte 2 — CSS Grid

¿Qué es CSS Grid?

CSS Grid es un modelo bidimensional: controla simultáneamente filas y columnas. Es perfecto para el layout macro de una página: headers, sidebars, grillas de contenido.

Conceptos clave

  • Línea de cuadrícula (grid line): las líneas numeradas que dividen el grid (empiezan en 1).
  • Track: el espacio entre dos líneas — una fila o una columna.
  • Celda: intersección de un track de fila y uno de columna.
  • Área: rectángulo de una o más celdas contiguas.
  • fr (fracción): unidad que representa una fracción del espacio disponible.

/* Layout clásico de página con áreas */
.layout {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  grid-template-columns: 250px 1fr;
  grid-template-rows: 64px 1fr auto;
  min-height: 100vh;
}

.header  { grid-area: header;  }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main;    }
.footer  { grid-area: footer;  }

Flexbox vs. Grid — ¿cuándo usar cada uno?

Usa Flexbox cuando…
  • El layout es unidimensional (fila o columna)
  • Necesitas distribuir ítems en una barra de navegación
  • Quieres centrar contenido vertical y horizontalmente
  • Los ítems tienen tamaños variables y quieres que crezcan/encojan
  • Construyes un componente: card, formulario, lista de tags
Usa Grid cuando…
  • El layout es bidimensional (filas y columnas)
  • Construyes el esqueleto de una página: header, sidebar, footer
  • Necesitas que ítems salten celdas o abarquen varias
  • Quieres columnas que se creen automáticamente con auto-fill
  • Diseñas una galería o un tablero tipo dashboard
✅ Regla de oro

No son excluyentes: Grid para el layout macro (estructura de la página) y Flexbox para los componentes (interior de cada bloque). En el Ejercicio 6 los usarás juntos.

01
Barra de Navegación
Flexbox display · align-items · justify-content · gap
Básico

Objetivo: construir una navbar horizontal donde el logo queda a la izquierda, los links al centro y el botón "Contacto" al extremo derecho.

02
Tarjetas de Productos
Flexbox flex-wrap · flex-basis · flex-grow · dirección columna
Básico–Medio

Objetivo: crear una grilla de tarjetas que se ajuste automáticamente: máximo 3 por fila, precio siempre al fondo de cada tarjeta.

Propiedades que practicas

  • flex-wrap: wrap — permite salto de línea
  • flex-basis: calc(33.333% - 1rem) — tamaño base para 3 columnas
  • flex-grow: 1 — cada tarjeta llena el espacio sobrante
  • flex-direction: column — dentro de la tarjeta para empujar el precio

Concepto clave — flex en columna

La tarjeta usa display: flex; flex-direction: column. Al poner flex-grow: 1 en la descripción, ella se expande y empuja el precio al fondo, sin importar cuánto texto tenga cada tarjeta.

03
Perfil de Usuario — Flexbox Avanzado
Flexbox flex shrink/grow · align-self · order
Medio

Objetivo: practicar las propiedades de los ítems individuales en tres escenarios reales.

04
Galería de Fotos
Grid repeat · fr · auto-fill · minmax · grid-column/row
Básico Grid

Objetivo: aprender las bases de CSS Grid creando una galería en tres variantes.

Referencia rápida — hoja de trucos

Flexbox en una imagen

/* Contenedor */
.container {
  display: flex;
  flex-direction: row | column;
  flex-wrap: wrap;
  justify-content: flex-start | center | space-between | space-around | space-evenly;
  align-items: stretch | flex-start | flex-end | center | baseline;
  gap: 1rem;
}

/* Ítems */
.item {
  flex: 1 1 0;         /* grow shrink basis */
  flex-grow: 1;         /* ocupa espacio sobrante */
  flex-shrink: 0;       /* no se encoge */
  flex-basis: 200px;    /* tamaño base */
  align-self: flex-end; /* alineación individual */
  order: -1;            /* aparece primero visualmente */
}

CSS Grid en una imagen

/* Contenedor */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 60px 1fr auto;
  grid-template-areas:
    "header header header"
    "sidebar main   main"
    "footer footer footer";
  grid-auto-rows: minmax(100px, auto);
  gap: 1rem;
}

/* Ítems */
.item {
  grid-area: header;        /* asigna área nombrada */
  grid-column: 1 / 3;       /* de línea 1 a 3 */
  grid-column: span 2;      /* abarca 2 columnas */
  grid-row: span 2;         /* abarca 2 filas */
  justify-self: center;     /* alinea horizontalmente */
  align-self: end;           /* alinea verticalmente */
}

/* Grid responsivo */
.responsive-grid {
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
}
