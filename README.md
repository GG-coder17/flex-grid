# Taller CSS Flexbox & Grid

6 ejercicios progresivos para dominar los layouts modernos en CSS.

## Estructura

```
flex-grid/
├── guia/
│   └── guia-taller.html        ← Abre en el navegador → imprime como PDF
├── ejercicios/
│   ├── 01-flex-navegacion/     ← display:flex, justify-content, align-items
│   ├── 02-flex-tarjetas/       ← flex-wrap, flex-basis, flex-grow
│   ├── 03-flex-avanzado/       ← flex-shrink, align-self, order
│   ├── 04-grid-basico/         ← repeat, fr, auto-fill, minmax, span
│   ├── 05-grid-areas/          ← grid-template-areas, grid-area, responsive
│   └── 06-flex-grid-dashboard/ ← CSS desde cero (ejercicio integrador)
└── soluciones/                 ← No abrir hasta intentarlo!
```

## Cómo usar

1. Abre `guia/guia-taller.html` en el navegador para leer la guía.
   - Haz clic en **"Guardar como PDF"** o usa `Ctrl+P → Save as PDF`.
2. Abre cada `ejercicios/0X-nombre/index.html` en el navegador.
3. Edita **únicamente** el archivo `styles.css` de cada ejercicio.
4. Busca los comentarios `/* TODO */` — indican qué propiedades agregar.
5. Consulta `soluciones/` solo si te quedas atascado.

## Progresión

| # | Ejercicio | Tema | Nivel |
|---|-----------|------|-------|
| 01 | Barra de Navegación | Flexbox básico | Básico |

| 03 | Perfil de Usuario | align-self, order, flex-shrink | Medio |
| 04 | Galería de Fotos | Grid básico, span, auto-fill | Básico Grid |
| 05 | Layout de Página | grid-template-areas, responsive | Medio Grid |
| 06 | Dashboard Completo | Flex + Grid desde cero | Avanzado |
